# React Draggable Test Branch

This branch is used for testing the `main` branch

## Setup

In the main branch: run `npm pack`, a `.tgz` file will be created

Install the file `npm i react-draggable-0.0.0.tgz`

<!-- npm i ./../react-draggable/react-draggable-0.0.0.tgz -->

Then start the dev server `npm run dev`
